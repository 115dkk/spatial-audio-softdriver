# 0004. EV 인증서는 한 번만 사고, 드라이버는 최소로 만들어 얼린다

상태: 채택, 2026-10-11

## 배경

Secure Boot를 켠 PC에 드라이버를 올리려면 Microsoft 증명 서명이 필요하고, 증명 서명은 제출할 때 EV 인증서가 유효해야 받을 수 있습니다. 한 번 서명된 드라이버는 EV가 만료된 뒤에도 계속 로드됩니다.

## 결정

EV 인증서(SSL.com 개인사업자, $359)를 한 번 삽니다. 사는 시점은 M3가 끝날 때입니다. 드라이버는 메커니즘만 가진 최소 형태로 만들고(ADR 0011), 서명을 제출하기 전에 계약(ABI v1)을 동결합니다.

## 결과

- 드라이버를 고칠 수 있는 기간은 EV의 1년입니다. 초기 사용자의 버그 보고를 받는 동안 그 기간이 남아 있도록 EV는 되도록 늦게 삽니다.
- M0부터 M2까지는 EV도 우리 드라이버도 없이 진행합니다. 개발 중에는 시험서명한 SAL 드라이버를 블랙박스로 씁니다(ADR 0005).
- 서명 제출 전에 Driver Verifier, IOCTL 퍼저, HVCI 로드, CodeQL, 형식 협상 매트릭스를 모두 통과시키고, `bio-abi`의 레이아웃을 해시로 기록합니다.
