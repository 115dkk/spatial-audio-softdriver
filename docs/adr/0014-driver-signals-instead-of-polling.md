# 0014. 폴링 대신 드라이버 신호를 쓴다

상태: 제안, 2026-10-11 (설계서 후보 6, 드라이버를 얼리기 전에 측정해 정함)

## 배경

구축기는 반 버스트를 일찍 잡으려고 1 ms마다 링을 들여다보고, Windows 기본 타이머(15.6 ms)를 `timeBeginPeriod(1)`로 바꿨습니다. 시스템 전체의 타이머 해상도를 바꾸는 일이라 전력을 더 쓰고, 그래도 최대 1 ms를 기다립니다.

## 제안

- READ를 보류해 두고, 반 버스트 분량이 쌓이는 순간 드라이버가 완료합니다. 이것은 ADR 0011에 이미 들어 있습니다.
- 여기에 더해 쓰기 패킷 알림(`IMiniportWaveRTOutputStream::SetWritePacket`, Windows 10 이상)을 구현하면 가상 DMA 위치를 기다리지 않고 쓴 즉시 링으로 넘깁니다. Microsoft 문서에 따르면 이때도 위치와 알림은 명목 속도로 진행해야 하므로, 클럭 도메인은 그대로이고 데이터만 일찍 나옵니다.

## 정해야 할 것

공간음향 엔진이 이 알림을 어떤 주기로 부르는지는 재 봐야 압니다. M2와 M3 사이에 측정해 v1에 넣을지 정합니다. 넣는다면 기록의 `qpc_written` 필드를 채우고 `FEATURE_WRITE_PACKET` 비트를 켭니다. 대가는 커널에 취소 안전 큐와 알림 처리 코드가 늘어난다는 것입니다.
