# 0016. 헤드폰 FIR, 빈 방향, LFE는 적재할 때 처리한다

상태: 채택, 2026-10-13. 2026-10-11에 제안했습니다(설계서 후보 8).

## 배경

구축기에서는 헤드폰 보정이 실시간 그래프의 별도 단계이고, 측정 BRIR이 없는 천장 중앙은 무음 채널로 자리만 채우며, LFE는 FC의 양이 IR을 빌려 씁니다. 세 가지가 모두 실행할 때의 그래프 문자열 안에 흩어져 있습니다.

## 결정

- `brir::prepare`가 헤드폰 FIR을 각 BRIR에 미리 접습니다. 둘 다 선형 시불변이라 결과가 같습니다.
- 레이아웃에 없는 위치는 렌더러의 VBAP가 이웃 방향에 나누므로 무음 채널이 필요 없습니다.
- LFE에 어떤 IR을 쓸지는 프로필의 정책으로 둡니다.
- 게인과 리미터의 순서(+36 dB 뒤 −1 dBFS 리미터)는 그대로 지켜야 하므로 엔진의 마지막 단계에 남깁니다.

## 정해야 할 것

M1에서 헤드폰 FIR을 접기 전과 후의 출력이 허용 오차 안에서 같은지 테스트로 확인한 뒤 채택합니다.

## 구현

- 헤드폰 FIR은 FFT 합성곱으로 각 BRIR에 접습니다. 직접 합성곱 기준과 상대 오차 1e-6 안에서 같습니다(`brir`의 시험).
- ~~두 귀가 모두 무음인 방향은 레이아웃에서 뺍니다.~~ 2026-10-15에 바꿨습니다(아래 고침). 이제 선언된 방향은 무음이어도 모두 레이아웃에 남습니다.
- 모든 방향과 두 귀에 같은 앞 지연(전파 지연)은 잘라 냅니다. 각 IR의 시작점(전체 최댓값의 −60 dB를 처음 넘는 표본)의 최솟값에서 1 ms 여유를 뺀 만큼을 모든 IR에서 똑같이 자르므로, 귀 사이와 방향 사이의 시간차는 그대로입니다. 프로필 키 `trim_leading_delay`(기본 true)로 끌 수 있고, 자른 표본 수는 `trimmed_leading_frames`에 남습니다.

## 2026-10-15 고침 (무음 방향을 남김)

- **결정.** 두 귀가 모두 무음인 방향도 레이아웃에서 빼지 않습니다. 레이아웃은 WAV 머리, 폴더 목록, 사이드카가 선언한 방향 그대로이고, `brir::layout`(머리만 읽음)과 `prepare`의 레이아웃은 받아들인 모든 세트에서 같습니다. `omitted_silent_directions`는 없앴습니다.
- **까닭.** 감독자는 BRIR을 가져올 때 표본을 디코드하지 않고 머리만 읽어 화면의 방향 목록, 시험음 방향 번호, LFE 경로를 정합니다(ADR 0013의 2026-10-15 보탬). 무음은 표본을 보아야만 알 수 있으므로, 준비가 무음 방향을 빼면 감독자가 본 번호와 엔진의 번호가 어긋나고, 무음인 FC로 정한 LFE 경로는 준비에서 실패했습니다.
- **대가.** 원래 이 규칙이 막던 일이 돌아옵니다. Impulcifer가 재지 않은 스피커를 0으로 채운 `hesuvi.wav`(예: FL/FR만 잰 14트랙)는 SL, BL, FC, SR, BR을 실제 방향으로 가지므로, 믹서가 그 방향으로 패닝한 소리(가운데 대사, 서라운드)와 FC로 보낸 LFE가 들리지 않습니다. 사용자는 잰 방향만 담은 폴더나 매핑 WAV를 가져와 이를 피합니다. 패닝에서 무음 방향을 건너뛰는 일은 엔진의 몫으로 남깁니다.
- **앞 지연 자르기.** 무음 트랙은 시작점이 없으므로 공통 앞 지연을 계산할 때 빼고, 자를 길이보다 짧은 무음 트랙은 무음 표본 하나를 남겨 필터가 비지 않게 합니다. 선언한 방향이 하나도 없는 세트만 빈 레이아웃 오류입니다.
