# 0007. 디코더와 입출력은 이미 있는 크레이트를 쓴다

상태: 채택, 2026-10-11

## 배경

E-AC-3 JOC와 TrueHD 디코더를 맨바닥부터 쓰는 데는 몇 달이 듭니다. WASAPI 바인딩, 리샘플러, 실시간 링도 검증된 구현이 있습니다.

## 결정

- E-AC-3 JOC와 TrueHD는 harletty-bridge의 `eac3` 크레이트와 `truehd` 크레이트(둘 다 Apache-2.0)를 씁니다. `eac3`는 crates.io에 없으므로 git 의존성으로 커밋을 고정해 들이고, `deny.toml`의 `allow-git`에 그 저장소 하나만 더합니다.
- 출력은 `wasapi`, 리샘플링은 `rubato`, 실시간 SPSC 링은 `rtrb`를 씁니다.

## 결과

- `eac3`의 패치 노트에는 JOC 경로에서 잡음이 나서 변경을 되돌린 기록이 있습니다. DD+ 어댑터는 Omniphony 출력과 비교하는 골든이 생기기 전에는 '구현됨'으로 표시하지 않습니다.
- `eac3`가 객체 신호와 위치를 어떤 모양으로 내주는지, 실시간에서 할당하는지, AC-3도 다루는지는 어댑터를 쓰면서 확인합니다.
